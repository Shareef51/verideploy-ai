# Initial Service Level Objectives

These are engineering targets, not measured production claims.

| Capability | SLO target |
|---|---|
| Public gateway availability | 99.9% monthly |
| Gateway health endpoint p95 | < 150 ms |
| UI static navigation p95 | < 1.5 s on reference broadband |
| Realtime event delivery (future) p95 | < 1 s after durable event publication |
| Investigation creation acceptance (future) p95 | < 500 ms |
| RPO for persistent production data | <= 5 minutes target |
| RTO for core service restoration | <= 60 minutes target |

Error budgets and load-test thresholds are introduced in later observability/performance milestones. No performance number in this document is represented as measured yet.
